# README

## Proposal

A SRE would mostly automate using IaC like Terraform or GitOps with Kubernetes.

However, there is a class of problems not easily solvable with existing tools: Complex workflow that faces failures, uncertainty and is long running.

Durable Execution will become a useful tool in your toolbelt to solve this. Its most famous implementation is Temporal.

We will demo how Temporal can be leveraged in your day-to-day SRE scenarios.

Workshop includes:
- Getting rid of cron forever for long-running jobs
- Granting superpowers to your humble scripts
- Leveraging for Day-2 DB operations: pgroll, pgstream, sqldef
- Just-in-Time access flow with Cloud Native Postgres (CNPG)
